# Clash三段式配置生成工具

## 📋 功能介绍

将Clash节点配置文件和静态住宅IP信息结合，智能生成三段式配置：

| 流量类型 | 处理方式 | 说明 |
|---------|---------|------|
| 国内网站 | 🚀 直连 | 国内域名和IP直接连接 |
| 国外网站 | ✈️ 代理 | 通过前置中转节点代理 |
| AI服务 | 🏠 静态IP | Claude、ChatGPT等使用住宅IP |

## 📁 文件结构

```
├── config_generator_web.py      # Web可视化版本（主程序）
├── 启动Web界面.bat               # Web界面启动脚本
├── README.md                    # 本文档
├── 节点信息.yaml                 # 输入：节点配置文件
├── 静态住宅IP.txt                # 输入：静态IP信息
└── 三段式节点信息.yaml            # 输出：生成的配置文件
```

## 🚀 快速开始

双击 `启动Web界面.bat`，系统会自动打开浏览器访问界面。

功能特点：
- 拖拽文件上传
- 实时日志显示
- 配置预览和下载
- 现代化UI界面

## 📝 输入文件格式

### 节点信息.yaml
包含Clash代理节点的YAML配置文件，支持标准Clash配置格式。

示例结构：
```yaml
proxies:
  - { name: '🇭🇰 香港 01', type: trojan, server: xxx, port: 443, ... }
  - { name: '🇺🇸 美国 01', type: trojan, server: xxx, port: 443, ... }
```

### 静态住宅IP.txt
SOCKS5代理信息，格式如下：
```
username:password@server:port
```

示例：
```
840172f6:d02d048c@us234.kookeey.info:24209
```

## ⚙️ 生成的配置说明

### 代理组结构

| 代理组 | 类型 | 说明 |
|-------|------|------|
| ✈️ 前置中转-自动 | url-test | 自动选择延迟最低的节点 |
| ✈️ 前置中转 | select | 手动选择中转节点 |
| 🌍 国外网站 | select | 国外网站默认代理组 |
| 🏠 静态住宅IP | select | 静态住宅IP代理 |
| 🤖 AI专用 | select | AI服务专用代理组 |

### 规则说明

1. `GEOSITE,CN,DIRECT` - 国内域名直连
2. `GEOIP,CN,DIRECT` - 国内IP直连
3. AI相关域名（Claude、OpenAI、Gemini等）→ `🤖 AI专用`
4. `MATCH` → `🌍 国外网站`

## 💡 使用建议

1. **定期更新节点**：当节点信息变化时，重新运行工具生成配置
2. **检查静态IP**：确保静态住宅IP有效，否则AI服务可能无法连接
3. **自定义规则**：根据需要修改 `config_generator_web.py` 中的规则部分
4. **备份配置**：重要配置更改前建议备份原有配置

## 🔧 故障排查

### 问题1：运行报错 "No module named 'yaml'"
**解决**：本工具已移除对PyYAML的依赖，如果遇到此错误，请确保使用的是最新版本。

### 问题2：生成的配置文件格式错误
**解决**：
1. 检查输入文件是否为UTF-8编码
2. 检查节点文件是否为有效的YAML格式
3. 检查静态IP文件格式是否正确

### 问题3：静态IP无法连接
**解决**：
1. 检查静态IP格式：`username:password@server:port`
2. 确认静态IP是否有效且未过期
3. 检查网络连接是否正常

### 问题4：AI服务无法访问
**解决**：
1. 检查 `🏠 静态住宅IP` 代理组是否选择了有效的静态IP
2. 确认静态IP可以正常连接
3. 尝试切换到 `✈️ 前置中转` 作为备选
